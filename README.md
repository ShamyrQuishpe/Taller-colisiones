# Taller de colisiones

Proyecto de Unity 6000.6.2f1 que continúa el ejercicio de clase sobre gravedad, colisiones e interacciones.

## Objetivo y controles

Recoge las cinco monedas. El personaje avanza automáticamente y cambia de dirección al chocar con una pared. Presiona **Espacio** para saltar (puedes hacer un segundo salto en el aire). Al recoger todas las monedas aparece la pantalla de victoria; presiona **R** para reiniciar.

## Abrir el proyecto

Abre esta carpeta desde Unity Hub con la versión indicada. La escena principal es Assets/Scenes/SampleScene.unity.

El repositorio guarda el proyecto fuente (Assets, Packages y ProjectSettings). La build WebGL se genera desde Unity y se publica por separado en itch.io.
